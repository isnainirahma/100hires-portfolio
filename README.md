# 100hires-portfolio 
## Overview
This project was created to document my setup process for the 100Hires portfolio task. Since this was my first time using tools like Cursor IDE, Claude Code, and Codex, the process felt quite challenging at the beginning. However, I continued exploring the tools and learning step by step throughout the setup.

## Tools Installed
- Cursor IDE
- Claude Code Extension
- Codex Extension
- GitHub

## Setup Process
1. Installed Cursor IDE on Windows.
2. Connected Cursor with my GitHub account.
3. Explored the Cursor interface and learned how the extension system works.
4. Installed Claude Code and Codex extensions.
5. Created a public GitHub repository.
6. Edited and organized this README.md file.

## Challenges
During the setup process, I experienced several issues:
- The Cursor website was difficult to access at first.
- Extension installation took longer than expected.
- Some parts of the login and setup process were unfamiliar to me.

## How I Solved Them
To solve those issues, I:
- Tried different internet connections.
- Restarted Cursor and waited for the installation process to finish properly.
- Searched for tutorials and online documentation to better understand the workflow.

## What I Learned
This experience helped me become more familiar with GitHub, AI-assisted tools, and technical setup processes. Even though everything was new to me, I enjoyed learning through the challenges and becoming more comfortable exploring unfamiliar technology independently.
